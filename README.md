# Aaron Huntley's website

Source for <https://aaron-huntley.github.io/>, a personal site built with
[MkDocs](https://www.mkdocs.org/) and the
[Material](https://squidfunk.github.io/mkdocs-material/) theme.
The site also uses quarto rendering for some blog posts.

The formatting for this site was originally inspired by [Luke Trujillo](https://ltrujello.github.io).

Since creation the website has seen many updates and is now maintained with the help of AI.
